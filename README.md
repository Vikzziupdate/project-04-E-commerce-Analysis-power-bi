# Project 4: Data Visualization – E-Commerce Sales Analysis

**Introduction**

This project focuses on analysing an e-commerce sales dataset using Microsoft Power BI. The objective is to transform raw transaction data into meaningful visual reports that support better business decisions.

**Methodology**

I imported the dataset into Power BI, performed data cleaning using Power Query, corrected data types, handled missing values and created calculated measures using DAX.

**Visualizations**

I developed interactive visualizations to examine:
- Total orders and order value.
- Sales trends over time.
- Revenue by product.
- Order status distribution.
- Payment methods.
- Customer acquisition sources.
- Coupon code performance.

**Key Findings**

The analysis revealed that chairs and printers generated the highest order values. Instagram was the leading referral source, while cancelled orders represented approximately 20.8% of all transactions.

**Conclusion**

The project demonstrates how Power BI can transform raw data into meaningful insights. The dashboard provides a clearer understanding of sales performance, customer purchasing patterns and order management, helping businesses identify areas that require improvement.
